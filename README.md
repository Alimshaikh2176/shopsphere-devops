# ShopSphere

Three-tier e-commerce application built as an end-to-end DevOps portfolio project.

## Application Architecture
- Frontend: React + Nginx
- Backend: Python + FastAPI
- Database: PostgreSQL

## DevOps Tools
- Linux
- Git and GitHub
- AWS
- Docker
- Terraform
- Ansible
- Jenkins
- Kubernetes
- Helm
- Prometheus
- Grafana
